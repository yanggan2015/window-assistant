# 窗哨 WindowWatch

桌面窗口监控与 AI 辅助工具：选中任意窗口（串口工具、微信、浏览器、Word、视频……），它持续截图、感知内容变化，变化稳定后调用**本地 Ollama 视觉模型**分析"发生了什么、要不要处理、怎么处理"，以贴边停靠栏形式给出建议；授权下可向目标窗口输入文本/回车完成动作。

- 技术栈：C# / .NET 9 / WPF，纯 BCL + Win32，**零 NuGet 依赖**，全离线。
- AI 后端：本地 Ollama（默认 `http://localhost:11434`，模型 `qwen2.5vl:7b`）。

---

## 一、环境要求（本机已基本就绪）

| 依赖 | 用途 | 状态 |
|---|---|---|
| .NET 9.0 SDK | 构建/运行 | 已安装 |
| Ollama | 本地视觉推理服务 | 待安装（见下） |
| 视觉模型 qwen2.5vl:7b | 截图理解 | 需 `ollama pull` |

### 1. 安装 Ollama 并拉取模型
```powershell
winget install --id Ollama.Ollama
ollama pull qwen2.5vl:7b        # 约 5GB，需一定时间；自动使用 NVIDIA 显卡
```
> 若无 8GB 显存可用 `ollama pull llava:7b`（更轻，中文/OCR 略弱）。
> 显存充足想更强：`ollama pull qwen2.5vl:14b`。

验证：`ollama list` 应能看到模型；浏览器打开 `http://localhost:11434` 有响应即服务正常。

## 二、构建与启动

```powershell
cd C:\code\window-assistant\WindowWatch
dotnet build -c Release
# 或直接运行已构建产物：
.\bin\Release\net9.0-windows\WindowWatch.exe
```

启动后桌面右侧会出现一个半透明贴边栏。

**三种方式随时呼出/隐藏工具条：**
1. **快捷键 `Ctrl+Alt+W`**（最省事，立即展开/收缩）
2. **系统托盘图标**（桌面右下角时钟旁，双击或右键 →「显示/隐藏工具条」）
3. **鼠标移到屏幕右侧边缘**（悬停区已加大，会看到一个带蓝点的小把手，悬停即展开）

> 程序为单实例运行；再启动会提示"已在运行"并退出。

## 三、使用流程

1. **加窗口**：点工具栏「＋窗口」→ 列表里选择要监控的窗口（如 SecureCRT、微信）→ 选一个"窗口画像"（串口/微信/浏览器/文档/视频/通用）→ 确定。
2. **开始监控**：工具自动周期性截图该窗口，内容稳定变化后触发一次 AI 分析，结果（发生了什么/建议动作）显示在面板；事件日志实时滚动。
3. **立即分析**：点「分析」强制分析当前画面一次。
4. **暂停/继续**：点「暂停」停止该会话轮询。
5. **执行动作**（可选）：分析结果下方会出现"推荐动作"。点某个动作按钮：
   - 若**自动操作未开启**：仅复制该动作文本到剪贴板，提示你在设置中开启。
   - 若**已开启**且勾选"逐动作确认"：弹出确认后再向目标窗口输入该文本并回车。
6. **贴边隐藏**：鼠标离开工具条自动收缩成边缘细条；鼠标移到细条处自动展开。可在设置里改边缘位置、是否吸附被监控窗口。

## 四、安全说明（重要）

- **自动操作默认关闭**。请到「设置 → 自动操作」手动打开「允许自动执行」。
- 自动执行只向**当前监控会话的目标窗口**注入输入，绝不操作其他进程。
- 微信、网银等敏感应用请谨慎开启自动执行；建议保持"每次动作前确认"。
- 所有截图与分析都在本机完成，不联网上传。

## 五、常见问题

| 现象 | 处理 |
|---|---|
| 面板提示"Ollama 未就绪" | 安装并启动 Ollama（托盘图标出现），然后到设置点"校验连接" |
| 提示"未找到模型 qwen2.5vl:7b" | 执行 `ollama pull qwen2.5vl:7b` 或在设置里改模型名后校验 |
| 视频/某些程序画面分析是黑屏/空白 | GPU 硬件加速窗口 PrintWindow 截不到，需让该窗口在屏幕上可见（用屏幕回退）；完全遮挡/最小化无法截取 |
| 触发过于频繁/过少 | 设置里调大/调小"冷却(秒)"与"差异阈值" |
| 自动操作没生效 | 确认已开启"允许自动执行"；目标窗口需可见、未被其他置顶窗口完全遮挡 |

## 六、配置

程序目录下 `config.json`（可手改，也可在界面设置里改）：
- `ollama`：地址 / 模型 / 超时
- `capture`：轮询间隔 / 差异阈值 / 冷却 / 稳定帧数
- `dock`：贴边位置 / 自动隐藏 / 吸附目标窗口
- `automation`：允许自动执行 / 逐动作确认
- `sessions`：已监控窗口（按进程/标题/类名，重启自动重挂接）

   ├─ WindowPicker.cs       窗口枚举
   ├─ WindowCapture.cs      截图 + dHash 变化检测

   ├─ MonitorEngine.cs      监控引擎（多会话编排）
